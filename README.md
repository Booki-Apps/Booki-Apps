# Welcome to Booki Apps

**Minimalist design, complex engineering.**

</div>

---

**Booki Apps** is a software development hub focused on creating diverse, high-quality applications. From language learning tools to developer utilities and interactive games, we aim to build scalable and intelligent software.

## > What We Build

*   **Language & Education:** Applications dedicated to learning Mandarin Chinese, interactive dictionaries, and language study tools.
*   **Developer Tools & AI:** Open-source utilities, AI-integrated workflows (Agents, Context, Skills), and CLI integrations for modern development.
*   **Entertainment:** Lightweight games and interactive digital experiences.

## > Our Repository Structure

We maintain a hybrid ecosystem to balance open collaboration and secure development:
*   **Public Repositories:** Open-source libraries, UI components, development templates, and community tools. Feel free to explore!
*   **Private Repositories:** The core architecture, backend services, and production-ready applications for our official releases.
